# AtlasCloud CLI Homebrew tap

Install [AtlasCloud CLI](https://github.com/AtlasCloudAI/cli#readme) with Homebrew on
macOS or Linux. The formula is named `atlascloud` and installs the `atlas` command
for calling AtlasCloud chat, image, and video APIs from your terminal and scripts.

This repository contains the distribution formula. Public installers, release archives,
and command documentation are maintained in [AtlasCloudAI/cli](https://github.com/AtlasCloudAI/cli).

## Install

With [Homebrew](https://brew.sh/) installed:

```bash
brew install AtlasCloudAI/tap/atlascloud
atlas version
atlas --help
```

Or add the tap explicitly:

```bash
brew tap AtlasCloudAI/tap
brew install atlascloud
```

The formula provides prebuilt binaries for macOS Intel and Apple Silicon, and Linux
x86-64 and ARM64. See [`Formula/atlascloud.rb`](Formula/atlascloud.rb) for its pinned
release version, download URLs, and checksums.

## Quick start and documentation

Start with the [CLI API caller workflows](https://github.com/AtlasCloudAI/cli#api-caller-workflows)
for authentication, model discovery, cost estimates, and generation examples.
API calls require an AtlasCloud account and credentials; installation itself does not.

## Update or uninstall

```bash
brew update
brew upgrade atlascloud
brew uninstall atlascloud
```

Report CLI problems in [AtlasCloudAI/cli issues](https://github.com/AtlasCloudAI/cli/issues).
The formula is generated by the upstream release process; do not hand-edit release versions or checksums.

## From installation to model discovery

Check the local executable before configuring account access:

```bash
atlas version
atlas --help
```

For API access, follow [authentication and API caller workflows](https://github.com/AtlasCloudAI/cli#api-caller-workflows)
and use your own account credentials. Once authenticated, discover available
models and inspect one model's required parameters before constructing a call:

```bash
atlas models list --type video --json
atlas models get MODEL_ID --json
```

Replace `MODEL_ID` with an ID from the current catalog. These commands discover
metadata; they do not start a video generation. The upstream guide separately
shows cost estimation and billable chat/image/video calls. Model availability,
parameters, and prices must be read from the current service.

[The CLI reference](https://www.atlascloud.ai/docs/en/cli) and
[workflow examples](https://github.com/AtlasCloudAI/cli/tree/main/examples)
cover scripts and asynchronous jobs after installation.

## Diagnose the installation layer

```bash
brew info --formula AtlasCloudAI/tap/atlascloud
command -v atlas
atlas version
```

The package name and command name differ. If `atlas` is missing or resolves to a
previous installation, inspect Homebrew's linking output and your PATH before
assuming authentication is the cause. Include the OS/architecture, formula
version, install method, and exact error in a report.

Download or checksum failures concern the pinned archive in
[the formula](Formula/atlascloud.rb); report them in
[this tap's issues](https://github.com/AtlasCloudAI/homebrew-tap/issues).
`Not logged in`, model selection, and API errors belong with
[the upstream CLI documentation and support](https://github.com/AtlasCloudAI/cli#troubleshooting).
Do not include credentials in reports.
